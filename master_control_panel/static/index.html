Single-System HWID Lock Overview

Strict security guard: ensure each license runs on exactly 1 system without unauthorized duplication

🔒 How Single-System Binding Works

When a client launches TradePulse Personal on their computer, their unique hardware fingerprint (Motherboard UUID + CPU + Machine GUID) is bound to their 1-year license key. If they copy the executable to a second computer, the app immediately blocks execution with an Unauthorized System lock screen.

If a client buys a new PC or requires multi-machine access, you can use the Reset HWID or + Multi-PC buttons in the licenses table.
