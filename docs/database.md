# Database Schema & Entity Models

## Database Tables

TradePulse AI uses normalized relational tables:

- **`users`**: User authentication records, hashed passwords, roles.
- **`user_preferences`**: Global filter thresholds, min AI scores, quiet hours.
- **`telegram_accounts`**: Linked Telegram chat IDs, username, muted status.
- **`telegram_link_codes`**: Temporary 6-character linking tokens with UTC expiry.
- **`markets`**: Supported market types (`DIGITAL_OPTIONS_STYLE`, `CRYPTO`, `FOREX`, `STOCKS`).
- **`assets`**: Asset pairs, symbols, decimal precision, data source mapping.
- **`patterns`**: User-configured trading strategies with JSON rule ASTs.
- **`pattern_versions`**: Immutable snapshots of pattern modifications.
- **`pattern_images`**: Visual reference image metadata and secure storage paths.
- **`signals`**: Verified research signals generated by the engine.
- **`signal_events`**: Real-time lifecycle events (ticks, target reaches, expirations).
- **`signal_technical_snapshots`**: Permanent technical indicator snapshots at signal creation.
- **`signal_ai_analysis`**: Structured AI scoring, bias, reasoning, and risk evaluations.
- **`signal_results`**: Final outcome (Win/Loss/Tie), PnL %, exit prices.
- **`backtests`**: Historical replay executions with win rates, equity curves, trade logs.
- **`audit_logs`**: Security, login, and modification audit trail.
